# Test Brief Rules — BookVizion v6 likeness tests (Folio gate conditions T1–T4, 2026-10-18)

Applies to EVERY test brief, every style, no exceptions. Trinity applies; no re-gate needed.

T1 — Identity beats kit proportions. Every Harlow brief carries this line verbatim: "Harlow keeps his canonical facial proportions and gently enlarged eyes; the kit changes the finish only." Same rule for Maya's cartoon head proportion in Kit D (Semi-Real Painterly) and everywhere else: kits change the finish/medium, never the character's designed proportions. Pixel's tolerance: head-to-body ratio within about 15% of the reference.

T2 — One job per reference (Toolbox §1). Attach order follows Recipe System Part 2: (1) the approved reference portrait (likeness, markings, proportions), (2) the recipe text, (3) the style kit block as TEXT ONLY. The Drive photo master (Harlow) is for identity only and is NEVER used as the base image — a Semi-Real pass over the real photo is the shortest route to photoreal and is banned.

T3 — No lens blur in any style. No depth of field, bokeh, or background blur (this overrides Pixel's 3D depth-of-field note unless Jon says otherwise). Separate subject from background with value contrast and rim light.

T4 — Kit C (3D Animated) carries an extra negative: no recognizable studio character design or house look (in the kit's Negatives now).

Rounds cap (agreed with Folio): at most 2 REPAIR passes per test ("Correct only [problem]. Do not redesign the character."). If a style still fails after 2 repairs, the KIT goes back for rework — not a third pass. Never feed a drifted image into the next edit.

Judging: every image must read as an illustration at tile size AND full size — no pores, individual strands, lens blur, photographic lighting, or known-studio look. Judge the Semi-Real Painterly test at 110px, 168px, and 100%.

Gate-and-bank: after the step-1 reference portraits pass, bank them (file + md5 into the recipes' BANKED FILE / VERSION NOTE) BEFORE any style test runs. Each kit's first passing test becomes that kit's reference anchor images.

TILE DELIVERABLES (Jon/Pixel, 2026-10-18 — Pixel's Revision 2 at the end of the v6 shot list + "v6 Harlow full-body tile crop guide" in 01_INBOX govern): for EACH Harlow style, deliver two files: (1) the 2400x2400 full-body master, Harlow's head at least 20% of the frame width; (2) the 1:1 head-and-chest tile crop from that master, per Pixel's crop guide.
