# BookVizion

**Branch policy:** work happens on the latest *-vN / project branch. List branches before editing. Never assume the GitHub default is the working line. Working line: `bookvizion-v1` (GitHub default is `main`).

> Anybody's story. Anything imagined. Made into a real book.

Done-for-you custom illustrated books — the client uploads anything (voice memo, doc, PDF, or just talks), the pipeline returns a finished hardcover plus a private interactive review site with approval gates at every stage: storyline → likeness → spreads → print.
