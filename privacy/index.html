Privacy Policy — BookVizion Admin

Effective October 25, 2026

BookVizion Admin is an internal administration tool operated by BookVizion (bookvizion.com). It is used by BookVizion's operator to organize and produce custom storybooks. This page explains what data the tool accesses and how that data is handled.

Data the app accesses

The app signs in with a Google account and, with that account holder's permission, accesses Google Drive in read-only mode: it can view files and folders (for example, book project files and character recipe documents) but cannot change or delete them. Sign-in also provides the account's email address so the tool can confirm who is signed in.

How the data is used

Google user data is used only to display and organize the account holder's own Drive files inside the admin tool, as part of producing their books. It is used for nothing else.

Storage

An access token is stored on BookVizion's web server so the tool can reconnect without asking for sign-in every time. File contents are fetched on demand when a page is viewed; they are not copied to any other service.

Sharing

Google user data is never sold, rented, or shared with third parties, and is never used for advertising.

Limited use

BookVizion Admin's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Your choices

Access can be revoked at any time from the Google Account permissions page. Questions about this policy or about data handling can be sent to jonbeatz@gmail.com.

Changes

If this policy changes, the updated version will be posted on this page with a new effective date.
